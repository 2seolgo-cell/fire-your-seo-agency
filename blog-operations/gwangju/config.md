# 광주사무소 설정

| 키 | 값 | 확인 기준 |
|---|---|---|
| office | gwangju | 변경하지 않음 |
| 사무소 | 법무법인 로연 광주사무소 | 운영 대상 |
| blog_url | 미설정 | 사용자 확정 필요 |
| blog_id | 미설정 | URL 확인 후 입력 |
| 공식 홈페이지 URL | 미설정 | 공식 여부 확인 |
| 공개 연락처·주소·시간 | 미설정 | 사무소별 최신 공식 정보 확인 |
| 내부 원고 작성 역할 | 미설정 | 원고는 내부 직접 작성 |
| 법률 검토 역할 | 미설정 | 담당 변호사 |
| 사용자 승인 역할 | 미설정 | 수정·발행 승인 주체 |
| 계정 작업 역할 | 미설정 | 승인 버전만 적용 |
| 통계 제공 역할·범위 | 미설정 | 비식별 집계만 수령 |
| 시간대 | Asia/Seoul | 모든 관측·집계 |
| 설정 확인일 | 미설정 | 실제 확인일 |

블로그 URL 확정 전에는 실제 게시글·성과를 등록하지 않는다. 과거 대화의 URL·진단값은 자동 이관하지 않는다. 개인정보·비밀번호·토큰을 입력하지 않는다.

이 폴더의 [인벤토리](inventory.md), [우선순위](priorities.md), [성과](metrics.md), [검색·AI 관측](observations.md), [변경·승인](changes.md), [주제 후보](topics.md)를 함께 사용한다. 모든 행의 office는 `gwangju`여야 한다. 작업 지침은 [운영 안내](../README.md)를 따른다.
