# 성과 입력·전후 비교

## 자료와 입력

계정 보유자가 네이버 블로그 통계에서 실제 제공되는 지표만 비식별 집계하여 사무소 `metrics.md`에 입력한다. 개인정보가 포함된 원본 내보내기 파일은 저장하지 않는다. 블로그 조회수·검색 유입을 Search Console의 노출·클릭과 혼용하지 않는다. 네이버 블로그에 서치어드바이저·GSC 소유확인 및 통계 제공이 가능하다고 가정하지 않는다. 별도 홈페이지 통계는 별도 채널이며 블로그 수치에 합산하지 않는다.

입력 키는 office·post ID·지표·출처·집계단위·기간·추출시각이다. 같은 기간의 수정 통계는 정정 이력을 남기고 중복 합산하지 않는다. 블로그 전체 지표를 개별 글에 배분하지 않는다.

| 값 | 의미 |
|---|---|
| 미검증 | 자료 미제공·미관측 |
| 접근불가 | 출처를 열지 못함 |
| 제공안됨 | 해당 도구·범위에 지표 없음 |
| 0 | 실제 관측된 0. 출처와 기간 필수 |
| 적용제외 | 이 대상에 적용하지 않으며 이유 기록 |

## 비교

1. [비교 양식](templates/performance-comparison.md)에 변경 ID·실제 실행일 D·버전을 연결한다.
2. 기본 기준선은 D-28~D-1, 이후는 D+1~D+28로 같은 28일·시간대(Asia/Seoul)·지표·출처·글 집합을 사용한다. 변경일은 제외한다. 자료가 없으면 비교 불가다.
3. D+14에는 접근·내용·관찰 결과를 중간 점검한다. 성과를 비교하려면 전후 각각 같은 길이의 14일을 사용하고 28일 결과와 혼용하지 않는다.
4. 통계 지연을 고려해 기간 종료 3일 후 추출을 기본으로 하고 출처가 밝힌 지연이 더 길면 그에 따른다. 종료되지 않은 기간은 잠정으로 표시한다. 데이터 기준일과 추출일을 구분한다.
5. 절대 변화 = 이후 - 이전. 이전이 0보다 클 때만 변화율 = (이후-이전)/이전 × 100. 이전이 0이면 변화율 ‘산출불가(기준 0)’와 절대 변화만 표시한다. 결측은 계산하지 않는다.
6. 노출·클릭이 동일 범위로 제공될 때만 CTR = 클릭/노출 × 100. 노출 0은 산출불가. 조회수를 CTR 분모로 쓰지 않는다. CTR 전후 차이는 퍼센트포인트로 적는다.
7. 휴일·계절·다른 수정·신규 글·관찰 조건을 기록하고 변화가 수정 때문에 발생했다고 단정하지 않는다. 서울·광주 평균 순위나 서로 다른 지표를 합산하지 않는다.

## 검색·AI 관찰

사무소 `observations.md`에 실제 질의, 서비스·모델, 검색 모드, 시각·기기·지역·개인화 조건, 확인 범위, 결과 유형·위치, 정확한 출처 URL을 기록한다. 재측정은 동일 조건을 우선한다. 질의에 개인정보를 넣지 않는다.

AI 상태는 해당 글 인용 / 공식 홈페이지만 인용 / 브랜드만 언급 / 미관측(해당 응답 내) / 미검증으로 구분한다. AI 브리핑 미표시는 해당 질의·시점의 미표시이며 영구 미지원이나 인용 불가를 뜻하지 않는다. 순위 미발견은 ‘관측한 상위 N개 내 미발견’으로 적고 전체 순위를 추정하지 않는다.

해당 글 인용률 = 동일 질문·동일 조건의 실제 실행 중 해당 글 출처가 확인된 횟수 / 유효 실행 횟수. 미실행·오류는 분모에서 제외하고 별도 건수 표시. 블로그와 홈페이지 인용률을 구분한다. 결과 원문·스크린샷 대신 비식별 관찰 요약·공개 출처만 저장한다.

## 주기

주간은 이전 완료 주와 같은 요일 범위를, 월간은 완료된 달을 비교한다. 월 길이가 다르면 총합과 함께 관측일 수·일평균을 보고하고 기간 차이를 설명한다. 자료가 없는 지표는 미검증 그대로 보고한다. 자동 통계 계산·계정 연결·알림 예약은 구현되어 있지 않다.
