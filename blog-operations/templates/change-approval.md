# 변경·승인 기록 양식

- office / post_id 또는 원고 ID / 변경 ID: 미설정
- 작업 종류(기존 수정/신규 발행): 미설정
- 대상 URL / 내부 비식별 문서 ID: 미설정
- 검수 문서 ID / 확정 버전: 미설정

| 위치 | 현재 구조·문제 요약(원문 금지) | 내부 작성자가 확정한 변경 범위 요약 | 문체·사실·결과 유지 확인 | 근거 참조 ID |
|---|---|---|---|---|

- 변경 전후 전문: 승인된 내부 보관소에서만 대조, 저장소에 복사하지 않음
- 개인정보 검수 / 담당 변호사 사실·법률 확인: 미검증
- 사용자 승인 상태: 승인 없음
- 승인된 버전·작업·범위 / 승인 시각 / 승인 참조 ID / 승인 역할: 미설정
- 계정 실행 담당 역할 / 실행 시각 / 결과 / 공개 URL: 미설정
- 승인 버전 대조 / 공개 본문·모바일·링크 확인: 미검증
- 변경 취소 필요 시: 담당자에게 보고 후 별도 승인으로 처리
- D+14 / D+28 / 통계 확정 후 추출일: 미설정

사용자가 검토할 변경안은 비식별 상태로 제시한다. 빈 승인 필드와 단순 검수 통과는 승인으로 인정하지 않는다. 실행 후 내용이 달라지면 재승인한다.
