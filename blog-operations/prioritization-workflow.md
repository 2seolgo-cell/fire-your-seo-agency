# 게시글 개선 우선순위

사무소별 `priorities.md`에 확인된 과제만 등록한다. 현재는 실제 블로그 데이터가 없어 과제를 생성하지 않는다.

| 우선순위 | 기준 | 처리 |
|---|---|---|
| P0 | 확인된 개인정보 노출, 사실·결과 오류, 연락처 불일치, 중요한 법률 표현 오해 가능성 | 내부 즉시 확인·사용자에게 수정 승인 요청. 자동 수정 금지 |
| P1 | 실제 검색 의도와 불일치, 제목과 본문 결론 불일치, 근거 미확인, 직답·적용 조건 불명확 | 내부 작성자와 변호사 보완 요청 |
| P2 | 구조·가독성·관련 글 연결·갱신 필요 | 정기 검수 계획 |
| P3 | 신규 추정 주제·기타 가설 | 수요·중복 검증 후 내부 집필 여부 결정 |

개인정보 우려는 구체적 내용을 저장하지 않는다. 오류가 확정되지 않았다면 ‘확인 요청’과 ‘미검증’을 붙인다. 접근 불가만으로 P0 품질 오류로 분류하지 않는다.

동일 우선순위에서는 독자 피해 위험 → 확인된 유입이 있는 글의 문제 → 질문별 공백 → 예상 작업량 순으로 검토한다. 성과 자료가 없으면 유입 점수를 만들지 않는다. SEO 개선 가능성은 순위 상승 보장이 아니다.

과제 상태: 미착수 / 내부확인 / 보완요청 / 승인대기 / 승인 / 실행 / 사후확인 / 보류. 완료는 실행 증거와 승인 버전 대조 후 판정한다. 사무소·post ID·중복 과제 ID를 확인해 중복 집계하지 않는다.
