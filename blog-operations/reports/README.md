# 보고서 운영

[주간 양식](../templates/weekly-report.md)과 [월간 양식](../templates/monthly-report.md)을 복사해 실제 자료가 있을 때 작성한다. 현재 보고서는 생성하지 않는다.

파일명은 `seoul-weekly-YYYY-MM-DD.md`, `gwangju-weekly-YYYY-MM-DD.md`, `seoul-monthly-YYYY-MM.md`, `gwangju-monthly-YYYY-MM.md`로 구분한다. 날짜는 보고 기간 종료일 또는 월이며 Asia/Seoul 기준이다. 문서 안에도 office를 필수로 적는다.

각 보고서는 자기 사무소 원장만 참조한다. 종합본을 만들 경우 두 사무소를 병렬 표로 표시하며 출처가 다른 지표·순위는 합산하지 않는다. 공통 글은 책임 사무소에서만 집계한다. 보고서에 원고·사건 상세·개인정보·계정 화면 원본을 붙이지 않는다.

주간: 완료한 주의 검수·보완·승인·실행·미검증·다음 조치. 월간: 콘텐츠 상태 변화, 비교 가능한 성과, 질문 공백, 실제 AI 인용 관찰, 다음 달 내부 작성·검토 계획.

수정·발행·GitHub 반영 승인은 각각 별개다. 보고서 작성이나 과제 확정이 실행 승인을 대신하지 않는다. 실제 계정 자료 없이는 성과 보고를 완료로 표시하지 않는다.
